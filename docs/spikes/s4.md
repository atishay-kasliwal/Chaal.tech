# S4 Spike: LiveKit Proof of Concept

## Overview
This spike evaluates LiveKit as the video/audio transport solution for TeenPatti, replacing Cloudflare Realtime SFU.

## Implementation
- **Frontend**: React + Vite with LiveKit client SDK (custom UI for spike)
- **Backend**: Cloudflare Workers + Durable Objects for signaling and room management
- **Media Transport**: LiveKit (cloud-hosted)
- **Signaling**: Custom WebSocket signaling via Durable Objects to manage rooms and generate LiveKit tokens

## Implementation Notes

### MediaProvider Interface
The implementation follows the `MediaProvider` interface pattern mentioned in the specifications:
- Game code interacts only with the `MediaProvider` abstraction
- Concrete LiveKit implementation is hidden behind this interface
- This allows swapping video backends without changing game logic

### LiveKit Integration
- Uses `livekit-client` npm package for core functionality
- Room signaling handled by Cloudflare Durable Objects (WebSocket signaling)
- LiveKit token generation placeholder implemented (to be replaced with server SDK)
- Frontend connects to LiveKit rooms using URL and token from backend signaling

### Deployment
- **Frontend**: Deployed to Cloudflare Pages via `wrangler pages deploy`
- **Backend**: Cloudflare Worker with Durable Object deployed at https://s4-video-spike.katishay.workers.dev
- **Assets**: 3 files uploaded (2.41 KiB total / 1.00 KiB gzipped)
- **Bindings**: 
  - Durable Object: ROOM (Room signaling)
  - Assets: ASSETS (frontend files)
  - Environment Variables: LIVEKIT_URL, LIVEKIT_API_KEY, LIVEKIT_API_SECRET
