# PROBO PLAYER / CT chips

Transparent SVG assets: 5, 10, 20, 25, 50, 100, 200, 500 and 1000.
Each uses a 256 × 256 viewBox and exports at 1024 × 1024 by default.
These are scalable vector interpretations of the approved concept, rather than photographic renders.

Use `CasinoChip.svelte` for the app or use each SVG directly in website and promotional artwork.
The SVGs use Georgia with Times New Roman/serif fallbacks; convert type to outlines in a vector editor for fixed print reproduction.

Regenerate from the repository root with `node scripts/generate-chips.mjs`.
Preview the full collection at `/test-chips`.
Game pot/bet artwork is decorative; the amount beside it remains the actual game value.
